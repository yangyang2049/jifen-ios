# 多人计分样式原生接入验证（2026-10-31）

已在 iOS 项目中加入多人计分的纯色 / 彩色选择。原有「自定义加减分」开关和计分逻辑保持原样，样式入口紧接在开关下面，仍处于固定底部操作区；姓名列表滚动不会移动这两个设置项。

- 首页、计分 Tab、记录重开中的多人计分设置统一贴底，其他项目沿用既有布局。
- 「计分板样式」是一行入口，右侧显示当前模式和箭头。点击打开底部选择面板，完成按钮保持在底部。
- 纯色提供 12 种底色，浅色底自动使用深色文字；彩色保留原有玩家色序列。未选过样式的用户保持原有彩色默认。
- 模式和颜色以稳定标识保存，两种屏幕方向共用同一份偏好；切换模式保留上次纯色选择，清除应用数据时一并重置。
- 15 个样式和颜色名称键覆盖项目全部 47 个语言表，颜色名称不参与偏好存储。
- 手机及投屏复用现有 V2 面板、文字颜色字段，未增加协议字段；投屏末页空位、浅色底分页圆点也采用对应配色。

本轮自检发现并修复了两处产品问题：

1. SE 2 上较长的德语颜色名会把最后一两个字母挤到单独一行。色板现在按本地化词宽选择 4 / 3 / 2 列，德语在 SE 2 上采用 3 列，12 色仍全部位于固定完成按钮上方。
2. 毽球团体布局没有接入文字样式选择。姓名、主分、小分现在使用实际左右侧标识接入既有编辑器；iPad 上实际打开字号和颜色面板、调大字号并确认分数不变的复测已通过。

「计分板样式」左侧文字直接采用「自定义加减分」标题的样式：14 pt regular、`Theme.textPrimary`。原有自定义加减分的逻辑保持原样。

验证设备全部为模拟器：iPhone SE 2 / iOS 26.5、iPhone Duo / iOS 27.1、iPad Pro 13 M5 / iOS 26.5（深色模式）。Debug 构建成功，`git diff --check` 通过。
