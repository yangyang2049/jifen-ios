REVIEW NOTES

建议检查这几条流程

  1. 首页 → 创建小组（含选填简介）→ 分享小组号或二维码 / 加入。
  2. 约一场 → 报名 → 选择对阵 → 完赛。
  3. 离线完赛 → 待同步 → 联网提交 → 确认结果。
  4. 成员审批、临时成员认领、转让后退出。
  5. 申请加入后回到首页与"我的小组"，检查待审批回访入口与撤回。
  6. 把"网络与访问状态"切到请求加载中 / 请求失败，确认它们和"没有小组"不是一回事。
  7. 轮转与联赛：查看后续阶段的组织方式。
