# 九球追分 14710 交互 Demo

打开 `index.html` 即可交互，无外部依赖，也不连接线上账号。

- 手机和鸿蒙手表预览共用同一场示例；支持 2/3/4 人。
- 第二版手机布局按当前 iOS 记分板结构调整：无占位顶栏／底栏，姓名顶部固定、比分独立居中，返回／编辑／菜单悬浮。
- 「本局开球」叠放在玩家色块左上角，不改变姓名或比分位置；每人底部恢复 3 列 × 2 行分项次数统计，旧「自由球」位置改为本次规则中的「让杆」。短色块压缩统计格高度，避免遮挡比分。
- 普胜、犯规前置；大金、小金、黄金9在第二排；让杆独立且不计分。
- 操作弹窗仅保留玩家姓名、事件和分值；让杆使用有填充背景的独立按钮。确认弹窗仅显示付分人、分数变化及下一局开球人，完整说明放在菜单的「本场规则」。
- 双人让杆直接记录唯一对手，不再经过选人／确认层；多人保留继续击球人选择。两种操作均不计分、不换局，并可整笔撤销。
- 犯规一击完成双方转分，按钮固定显示「本人 −1／对手 +1」（双人）或「本人 −1／下家 +1」（多人），不把真实姓名塞入按钮；提示和明细保留姓名。两段分数文案各自不拆行，小屏允许整段换行。
- 小金默认本局开球人付分，可在确认页更正；可选择全员付分模式。
- 普胜默认座位上家，可确认实际付分人。
- 犯规付给下家 1 分，提示自由球，不结束本局。
- 普胜／小金后由赢家的座位下家开球；大金／黄金9默认赢家续开，开关关闭后改为赢家下家开球。按本次用户给出的具体示例实现，不标作全国统一规则。
- 整笔撤销恢复分数、局数、开球人和本次操作后的击球人。
- 让杆是示例内的非计分记录，不自动判断真实规则的让杆资格。
- 旧版规则标识仅作历史记录展示示例；未修改原生应用或迁移旧数据。
- 编辑比分会校验全员合计为 0，支持整笔撤销；不会把手工更正计入事件次数。

第二版已检查手机宽／窄容器及鸿蒙手表圆屏；手表按现有原生结构不展示手机的分项统计条。`verification.json` 记录本轮验证，`*-v2.png` 为第二版预览截图。

源文件：`source.html`（界面）、`rules.mjs`（纯规则）。

```sh
node build.mjs
node --test rules.test.mjs
```

`build.mjs` 把规则内联到 `index.html`，避免直接打开本地文件时的模块跨域限制。
