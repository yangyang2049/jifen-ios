小组功能「测试版」标识 + 底部说明 · 方案对比

共 3 处改动：① 首页「我的小组」标题加测试版标识；② 小组列表页加测试版标识；③ 列表底部加测试版说明（含支持运动 / 即将接入 / 反馈引导）。 下方所有尺寸、颜色、字号均按 App 现行浅色 token 还原（1dp = 1px），可直接对照 Compose 落地。

首页标识：推荐「绿色 soft 胶囊 chip」——与小组功能主色同源，18sp 标题后不抢戏，且能统一控制中英文长度。
列表页标识：列表页标题来自全局顶栏（MainActivity.titleResIdForRoute → group_list_title），不是页面内渲染，所以标识加在顶栏标题之后（已按此落地）。
底部说明：采用方案 D 卡片（不是条）。信息量三段（测试说明 + 支持运动 + 即将接入 + 反馈入口），一条 GroupBanner 装不下；卡片还能承载「去反馈」这个可点操作。空态下同样展示——新用户最需要这份说明。
文案口径：只说「测试版 + 欢迎反馈」，不承诺时间点、不写成免责声明；运动清单必须与小组契约 GroupSports（badminton / table_tennis / tennis / pickleball）逐字一致。

文案口径 · 建议
要说的三件事：① 这是测试版、体验会变；② 现在能玩什么；③ 有问题去哪说。
不要说的：
✕ 「敬请期待」「即将上线，敬请关注」——空话
✕ 具体时间（「11 月上线」）——做不到就是负体验
✕ 「不承担任何责任」类免责措辞——测试版不需要法律腔
运动清单口径 · 必须对齐契约
小组 GroupSports 当前只有 4 种：badminton / table_tennis / tennis / pickleball。
所以「目前已支持」只能写这 4 项，写羽毛球、乒乓球、网球、匹克球。
棋牌 / 台球在 GameType 里已有单项计分（掼蛋、升级、斗地主、麻将、UNO、象棋、围棋、八球/九球/斯诺克），但尚未进小组契约，只能放在「即将接入」里，并与后端 / 鸿蒙 / iOS 同步后再改文案。

与提案的两处偏差（都已按实际落地）：
1）列表页标识：实测有全局顶栏标题，改为挂在顶栏标题后，未新增页面内标题行。
2）说明卡展示范围：空态也展示——未加入任何小组的新用户最需要「这是测试版 + 现在支持什么 + 去哪反馈」。
仍待你确认：「即将接入」目前用简版（棋牌项目、台球等）。是否要展开成「掼蛋、升级、斗地主、麻将 / 八球、九球、斯诺克」，需与鸿蒙 / iOS / 后端同批改。
