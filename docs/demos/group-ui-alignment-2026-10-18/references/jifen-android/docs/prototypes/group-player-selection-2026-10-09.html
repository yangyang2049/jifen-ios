全能计分器 / 小组 / 直接选人

把名单展开，让选人就在当前页面完成

四种姓名呈现 · 补记赛果与训练编排共用 · 自定义控件

从“点席位再开选人框”改为“名单直接入席”

现有 GroupResultEntryScreen 与 GroupTrainingPlanScreen 都由席位触发 GroupMemberPickerSheet。下面的四个方案采用同一套直接选人流程，区别仅在名单的呈现方式，便于比较密度与辨认能力。

方案一屏密度辨认姓名适用判断
A 头像字最高首字 / 末字容易相同；需靠已选席位或辅助信息核对适合作为已选成员摘要，单独作为选人名单不推荐
B 头像下方姓名中等短姓名较清楚；长姓名受列宽和两行限制成员头像熟悉、名字普遍较短时可选
C 固定宽度横排较高整齐易扫视；长姓名尾部被省略，相似前缀不易区分能作为紧凑列表，需补充辨认信息
D 姓名自适应胶囊随姓名长度变化短名并排，长名自然换行，尽量显示完整姓名推荐；保留小头像作定位，完整姓名承担识别

同名成员在姓名下方显示成员号末四位。示例头像采用首字 / 末字；实际落地继续使用 GroupAvatar，优先显示已有头像，缺失时回落文字头像。训练切换场次时保留已填席位，同一场内成员不能重复，不同场次可复用；仍需沿用现有时间冲突与每人场次上限校验。
