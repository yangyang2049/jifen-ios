建议讨论的模块

首版前端闭环（P0）

✓
首页小组入口位于预约区之后，区分一次活动和长期组织，不新增底部 Tab。
✓
本地创建首版只开放固定项目的羽毛球小组，账号加入暂不开放。
✓
立即计分与约一场区分现在开打和提前安排，均关联当前小组。
✓
比赛与战绩待开始、比赛记录、排行榜和数据统计。
✓
临时成员添加、改名和停用可用；账号邀请显示后端接入后开放。

本轮明确不做

—
后端与多端同步小组数据同步、冲突合并、离线策略。
—
实时协作多人同时记分、观赛与在线状态。
—
消息系统邀请通知、审核、聊天和系统推送。
—
复杂权限管理员转让、角色矩阵与申诉流程。

需要定下来的产品规则

已确定：一个小组只绑定一个运动或棋牌项目，创建后不可更换。仍待确定：① 篮球等团队项目是固定队伍还是每场临时分队；② 排名按个人还是搭档/球队；③ 谁能新增或修正比赛；④ 是否允许非成员临时参赛。

当前原型假设

小组固定项目组局是一次活动成员可多组允许临时成员赛制按项目适配
