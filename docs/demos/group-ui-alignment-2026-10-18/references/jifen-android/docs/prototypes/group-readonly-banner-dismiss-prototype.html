小组「仅可查看」横幅 · 收起方案探索

现状：活动详情底部按钮区上方常驻一条灰色横幅（小组已归档 / 正在解散时），没有出口，每次进入都会占一行。 下面 5 个方案全部可交互。切换状态可预览两种文案。

方案 A · 右上角 × 一次性收起

推荐

横幅右侧加一个 ×，点了就收起。session 级记忆：本次进入小组期间不再出现，退出小组再进（或杀掉 App）会重新显示。 状态信息该知道的总归会再看到一次，不会永久丢。

✅ 改动最小：GroupBanner 加可选 onClose，一处组件全 App 受益。
✅ 不需要存储层，ViewModel 里一个 State 即可。
⚠️ 用户若永久不想看到，做不到（每次重进会再出现）。

方案 B · 长按收起

零占位

横幅本身不增加任何视觉元素，长按 600ms 收起（带进度线和震动反馈）。首次显示时在句尾带一次小灰字提示「长按可收起」。 适合不想让横幅长出按钮、保持纯文本说明的形态。

方案 C · 折叠成单行 chip

推荐

不消失，只变矮。常驻态压成一行「ⓘ 已归档 · 仅可查看」小 chip，点开展开长句，看完点「知道了」或点外部收回。 状态信息永远在场，但视觉高度从两行降到一行，与「外面短、里面长」的文案分层原则天然一致。

方案 D · × 二选一菜单 + 角落 ⓘ

可彻底关

点 × 弹出小菜单：「本次收起」/「不再显示」。选「不再显示」按 groupId + 状态 记忆（解散中→归档状态变化时横幅会回来一次）。 收起后按钮区角落留一个极小的灰色 ⓘ，点了可随时唤回横幅。

方案 E · 降级为卡片 footer 小字

去横幅化

干脆不用横幅形态：说明降级为按钮区下方的一行 11px 灰色小字（虚线分隔），类似免责声明的视觉权重。 常驻但完全不抢注意力，也无需任何交互。

方案对比

方案视觉占用可发现性实现成本信息丢失风险备注
A × 一次性收起收起后为 0高（× 一眼可见）极低（GroupBanner 加 onClose）无（重进重现）性价比最高，可与 C 组合
B 长按收起收起后为 0低（需提示文案）中（长按+进度动画）无（可撤销）形态最干净，但教学成本高
C 折叠单行 chip一行（约减半）高（永远在场可点）低（纯 UI 折叠）零最符合「外面短、里面长」既有原则
D × 菜单 + ⓘ收起后仅 ⓘ高高（菜单+持久化+状态键）低（有状态键兜底）诉求最强时才值得做
E footer 小字一行 11px—（无需交互）极低无彻底去掉横幅形态，最"低调"

建议：首选 C（折叠 chip），信息常驻但高度减半，且与 10-12 定下的「外面短、里面长」分层一脉相承； 若评审仍觉得 chip 碍眼，退而选 A（× 收起 + session 级重置），GroupBanner 加可选 onClose 参数即可，其他横幅场景未来也能复用。 B / D / E 作为备选保留。无论选哪个，「解散中→已归档」状态变化时都应重置收起态，重新提醒一次。
