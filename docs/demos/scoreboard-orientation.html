常驻入口

保留各项目的原有入口

编辑在右上角；返回在左下角；菜单在右下角。多人 / UNO 和投篮训练沿用原有两按钮，玩家长按编辑。拳击 / 斗地主原有底部中央 + 也保留。横竖屏属于低频设置，收进菜单的「屏幕方向」，行尾显示当前状态。不新增导航栏和方向按钮，比分铺满整个屏幕。

首次引导

「横竖屏在菜单里切换」

首次进入时，在菜单旁显示一次短提示。点击菜单后提示消失；也可点关闭。提示占用底部空隙，不弹遮罩，不要求用户先选方向。

菜单 → 屏幕方向
可选竖屏、横屏、跟随设备。比分与计时保留，并记住本项目的选择。
默认策略

新用户竖屏，老用户保留习惯

新用户手机首次默认竖屏；篮球和三人篮球暂仅支持横屏，后续单独处理。之后保存各项目选择。老用户已有偏好直接沿用，无偏好的旧项目首次仍横屏，待手动切换后开始记忆。iPad 默认跟随窗口尺寸。

进阶选项

菜单里显示当前方向

更多 → 屏幕方向，可选竖屏、横屏、跟随设备。默认采用固定方向，避免手持时误转。方向设置放在菜单靠前位置，当前选项直接高亮。发球三角始终指向对应球队；双打时位置还对应具体发球员。

方向与数据分离

方向放在菜单；新用户首次竖屏，之后按项目记住。老用户先保留横屏习惯。由 ScoreboardLaunchView 与共享方向服务统一默认值、迁移和一次性提示；系统旋转成功后再保存偏好。计分、局 / 盘、级牌、撤销、计时、发球 / 庄家 / 击球方及链接会话沿用当前实例。
