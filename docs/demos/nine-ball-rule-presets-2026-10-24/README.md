# 九球追分：规则预设与编辑 Demo

直接打开 `index.html`，无需构建、无外部依赖。此目录是独立交互设计稿，不修改原生 Swift 或旧的 14710 Demo。

推荐入口分两层：

- 赛制：民间追分 / 赛事积分。沿用现有分段控件样式，不再额外显示“赛制”小标题；说明问号放在弹窗主标题右侧。
- 民间默认使用14710；14710 / 1357 的选择放进“分值与开球”，两者共用本应用已约定的转分逻辑，仅默认分值不同，不作为主界面的独立版本。
- 现有分值、付分对象和续开调整收进“分值与开球”。左侧用此名称标明内容，右侧在收起时显示“调整”、展开后显示“收起”。修改后只出现“恢复预设”，不再额外显示“已调整”标签。
- 民间的开局分值摘要与说明顶部的分值条均列出犯规、普胜、小金、大金、黄金9；赛事没有独立黄金9，保持四项。黄金9读取当前设置的独立分值。
- 弹窗主标题右侧的问号打开说明，同一滚动页依次完整展开“民间追分”“赛事积分”“两者差异”，无需切换当前赛制或对比标签。三个标题左侧沿用首页 SectionTitleView 的绿色竖条：3×16、圆角2、文字间距8。两类说明分别读取各自分值与开球设置。
- 三段说明底部均有“遇到问题或有建议？ 去反馈”入口，参照小组功能的反馈行。点击直接显示“发布反馈”页，标题预填 `#九球追分# `，返回恢复原说明滚动位置；草稿在本次演示中保留。

已收敛为两类玩法入口，不再展示“三项平铺”的对比方案。

## 反馈入口对齐

原生小组在 `GroupViews.swift` 中使用 `FeedbackListView(initiallyCreate: true, initialCreateTitle: "#小组# ")`，由现有反馈页面处理登录及新建流程。九球原生落地应复用相同页面，传入 `initialCreateTitle: "#九球追分# "`，并沿用 `AppFeatureFlags.feedbackEntryEnabled`。

本轮仅修改 HTML Demo：页面演示一般反馈/功能建议/问题反馈类型、标题和正文，未连接线上接口，也不会发送真实反馈。没有编造外部反馈网址或应用跳转协议。

## 与现有框架的关系

复用当前人数、姓名、逐行分值加减和固定底部操作按钮的形态。去掉玩家小标题，将分值方案放进折叠区域，在各项分值之前选择。首局默认1号玩家开球，改选入口也收进“分值与开球”。分值数字仍支持直接键入，不额外显示输入说明；高级项收起，标题与开始按钮保持固定，内容区域滚动。

“恢复预设”默认隐藏，分值、开球人或其他规则选项偏离当前预设后才显示，放在折叠行右侧动作文字的左边，不额外占一行。恢复后按钮重新隐藏，玩家姓名与人数保留。

民间保留黄金9、小金付分对象、大金/黄金9续开、让杆。1357 的黄金9在此示例默认3分，14710默认4分；四个方案数字本身不能确定黄金9分值，均需在说明和调整入口中显示，不声称它是全国统一规则。

赛事积分为双人单打示例，隐藏黄金9、付分对象和让杆，增加同局第三犯分值、开球方式与比赛局数。第三犯单独记2分，不再同时加普通犯规1分。换局清零，撤销恢复全部状态。赛事允许开球方在符合小金条件时记小金，不复用民间“开球人不能是小金赢家”的限制。

三犯是同一选手在同一局分别累计的三次犯规，不要求连续。第三次犯规的完整处理是：犯规方本局判负、对手得2分、本局结束；不另加普通犯规或普胜分，也不直接判整场负。三次依次给对手1、1、2分，共4分；第3次只生成一条三犯判负记录。下一局开球依本场选择的赢家续开或轮流开球安排。

比赛局数默认10局，快捷选项为1/5/10/20，自定义范围1至99。数字按钮44×44，输入64×44，间距8；使用换行布局，空间够时输入框与按钮同排，不够时自动移到下一行。这里是总局数，不是抢到几局；平分进入加赛。

这些快捷局数是产品便捷选项，不是官方统一赛制。原先40/50局能对应[决金第7季整场安排](https://www.taiqiuhq.com/NewsDetail/6398587.html)，该季包含单打和双打轮次，不应直接套作日常单打默认值。原先20局仅是Demo初始选择。未依据局数承诺固定比赛时长：20局若平均每局3至6分钟，才对应约1至2小时，属于算术估计且不含休息。

比分编辑沿用姓名和积分输入。民间支持负分，合计非0仅提示，保留原生手动更正能力；赛事积分要求非负整数，不要求合计0。

可从“开始游戏”体验记分、犯规、三犯换局、撤销、手动编辑和记录。多人普胜/小金可选择付分人，让杆可选择继续人。这里是设置与记分差异的交互演示，不自动裁定真实球形。

## 赛事来源与命名边界

截至本次研究（2026-10-24）：

- [乔氏官网2019年说明](https://www.joy147.com/newsinfo/1195137.html)明确早期6/4/2及开球进9为小金。
- 已定位[决金第7季竞赛规程原文](https://mp.weixin.qq.com/s/1eM99Wc1Q9GNMT9Xm_dunw)，微信触发访问验证，尚未读到完整正文。
- 可读的[独牙传奇中式九球标准规则全文](https://alison-chang.com/duya-legends-tour-golden-nine-standard-rules/)是媒体转载，署名独牙中式九球竞赛组委会，落款2025-10-16。该文本使用10/7/4、合法开球进9算小金，同局累计第三犯对手得2分并结束本局。

因此 Demo 使用“赛事积分”，不标为“决金第7季官方版”或“最新官方版”。所示赛事开球方式和局数是可选的开局配置，不冒充特定赛季规定。决金战队赛中的单双打轮次、队员轮换未进入此示例。

本次未引入“黑金”或多套自定义命名管理。
