结论：三端分组一致，都是「由内向外」。第一组＝两条内弧（半径 6，左右各一条）先渐显；第二组＝两条外弧（半径 10，左右各一条）再渐显、内弧保持；随后两组一起淡出、停顿、循环。这正是你确认的「一 Visible → 二 Visible → 两个消失」。

Android 与 HarmonyOS 的 4 条弧 path 数据逐字相同，且都来自原静态 ic_menu_share.xml / ic_share.svg；iOS 用 addArc 半径 6 / 10、角度 −45°~45° 与 135°~225° 生成，几何等价。

⚠️ 顺带查出 3 处小差异（周期、减弱动效、iOS 中心点/未分享图标），详见第 04 节；都不影响分组结论。

02 · 时间线对照 红色竖线是同步播放头；切「统一 2400ms」可看三端对齐后的差别

每个色块表示一次状态切换：绿＝内弧渐显起点、蓝＝外弧渐显起点、灰＝两组一起淡出起点。iOS 每轮开头多 140ms 全暗停顿，因此周期 2400ms；Android / HOS 立即开始，周期 2260ms。

04 · 二次验证检查表 逐项从三端源文件读取，非目测

检查项结论依据
分组口径✅ 三端一致：由内向外iOS phase≥1 → radius 6；Android phase>=1 → innerAlpha；HOS step() → radioInnerOpacity，都是内弧先亮
几何一致性✅ 通过Android/HOS 4 条 path 逐字相等，且 ⊆ 原静态图标；iOS addArc 半径/角度等价 Lucide radio
节奏✅ 通过一 Visible → 二 Visible（第一条保持）→ 两条一起消失 → 停顿 → 循环，与你确认的口径一致
渐显时长✅ 340 / 380msiOS .easeInOut(duration: 0.34/0.38)；Android tween(340/380)；HOS animateTo duration 340/380
阶段间隔✅ 440 / 770 / 1050ms三端完全相同（iOS 为 nanoseconds 形式 440/770/1050）
起始透明度✅ 0.12三端均为 0.12 → 1 → 0.12，无硬切
触发条件✅ 仅分享中iOS isActive；Android animated = active；HOS isSharingUiActive；观看者卡片都传 false / 不用动画
后台停止✅ 基本通过iOS scenePhase + .task 取消；HOS pageActive + clearTimeout；Android LaunchedEffect 离开组合自动取消
减弱动效降级⚠️ HOS 缺失iOS accessibilityReduceMotion、Android ANIMATOR_DURATION_SCALE == 0 均降级静态；HOS 面板文件里 0 处相关判断，系统关动效后仍会播放
周期总长⚠️ 2400 / 2260msiOS 多 140ms 起始全暗停顿；Android / HOS 立即开始。感知差异很小，但确实不同步
淡出同步⚠️ Android 差 40msiOS/HOS 两组统一 340ms 淡出；Android inner 340ms、outer 380ms（各自 animationSpec），肉眼几乎看不出
缓动曲线⚠️ 两类iOS/HOS EaseInOut；Android FastOutSlowInEasing（近似 ease-out）
未分享时图标⚠️ iOS 不同iOS 仍用 square.and.arrow.up；Android/HOS 用完整 radio（ic_menu_share / ic_share）。上一轮说「iOS 已补齐同款图标」只在分享中成立
中心圆点⚠️ iOS 不同iOS Circle().fill(white) 实心；Android/HOS circle r=2 stroke=2 空心环。放大视图可直接对比
静态→动画切换✅ 不跳变Android/HOS core 与静态图标的中心圆点写法一致；分层 4 弧也是从静态图标拆出来的

汇总：核心分组与节奏 8 项全过；另有 6 项细微差异，其中「HOS 减弱动效缺失」最值得补，其余属于观感级、不影响定稿。

private var innerOpacity: Double { shouldAnimate ? (phase >= 1 ? 1 : 0.12) : 1 }
private var outerOpacity: Double { shouldAnimate ? (phase >= 2 ? 1 : 0.12) : 1 }

.task(id: shouldAnimate) {
    while !Task.isCancelled {
        try? await Task.sleep(nanoseconds: 140_000_000)          // 起始停顿（另外两端没有）
        withAnimation(.easeInOut(duration: 0.34)) { phase = 1 }   // 内弧渐显
        try? await Task.sleep(nanoseconds: 440_000_000)
        withAnimation(.easeInOut(duration: 0.38)) { phase = 2 }   // 外弧渐显
        try? await Task.sleep(nanoseconds: 770_000_000)
        withAnimation(.easeInOut(duration: 0.34)) { phase = 0 }   // 一起淡出
        try? await Task.sleep(nanoseconds: 1_050_000_000)
    }
}

// ic_sync_radio_inner.xml = 两条 r=6 弧；ic_sync_radio_outer.xml = 两条 r=10 弧
var phase by remember { mutableStateOf(0) }   // 0 全暗 / 1 内弧亮 / 2 两组亮
LaunchedEffect(Unit) {
    while (true) {
        phase = 1; delay(440L); phase = 2; delay(770L); phase = 0; delay(1050L)
    }
}

HarmonyOS · RemoteSyncEntryPanel.ets 
// ic_sync_radio_inner.svg = 两条 r=6 弧；ic_sync_radio_outer.svg = 两条 r=10 弧
private startRadioAnimation(): void {
  const step = (): void => {
    this.getUIContext().animateTo({ duration: 340, curve: Curve.EaseInOut },
      () => { this.radioInnerOpacity = 1; });
    this.radioTimer = setTimeout((): void => {
      this.getUIContext().animateTo({ duration: 380, curve: Curve.EaseInOut },
        () => { this.radioOuterOpacity = 1; });
      this.radioTimer = setTimeout((): void => {
        this.getUIContext().animateTo({ duration: 340, curve: Curve.EaseInOut }, () => {
          this.radioInnerOpacity = 0.12;
          this.radioOuterOpacity = 0.12;
        });
        this.radioTimer = setTimeout(step, 1050);
      }, 770);
    }, 440);
  };
  step();
}

06 · 结论与待拍板 本轮只做验证与展示，未改任何客户端代码

事项建议
分组口径✅ 维持「由内向外」，不用改。若你想要「左右交替」，只需交换各端 inner/outer 资源里的弧线归属（iOS 改两个 ArcGroup 的角度），时间参数一律不动
HOS 减弱动效建议补：读系统动效缩放，为 0 时把两组 opacity 固定 1、不启定时器（对齐 iOS / Android）
周期对齐建议给 Android / HOS 加 140ms 起始停顿，或去掉 iOS 的 140ms，三端统一 2400ms / 2260ms 二选一
iOS 中心点 / 未分享图标若要严格三端同款：中心点改成描边圆 r=2，未分享态也换成 radio（或另两端改成 iOS 的分享图标）。属于产品取舍，需你定
缓动 / 淡出 40ms观感级，可不改；若要像素级一致，Android 淡出统一 340ms 并换 Curve/插值

验证方式：从 3 端共 10 个源文件抽取 path 与常量后用脚本逐项比对；iOS 完整 xcodebuild（模拟器 destination）EXIT=0、Android compileHuaweiDebugKotlin 与 HOS assembleHap 均 BUILD SUCCESSFUL。本页动画用 rAF 按各端真实时间参数重放，便于直接对比，非真机录屏。
