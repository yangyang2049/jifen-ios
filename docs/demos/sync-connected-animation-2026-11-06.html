✓ 为什么「上黑下绿」会怪

状态色落在小字上：既不够醒目，又因亮绿浅底对比度不足而发虚；黑色大标题反而被绿色小字"抢注释位"。

✓ 推荐 P6 的逻辑

状态＝进行中，本来就该强调大标题；辅助说明降级为灰。绿色徽章 + 绿色大标题形成一处呼应，不再上下打架。

✓ 状态色不丢

P4/P5/P6 下绿色是状态色变量：连接中→琥珀 #B45309、重连中→琥珀、未连接→红 #DC2626；小标题恒灰，切 4 态验证。

推荐 P6，但 P1 也不算错：如果不想动颜色，最小改动是 P4（只把绿色调深） —— 保留你熟悉的层级，只修对比度。工具栏切「P1 现状 / P4 绿调柔 / P6 大绿小灰 ★」三者对比最直观。P5 会改文案，除非你确实想让「已连接到同步服务」当大标题，否则不建议；且 P5 的文案互换只在「卡片头部」落点生效，切到「页面大标题」时自动退回原结构。

  • 动画节奏（已定稿）：累积扩散 —— 周期 2.4s，第一组 0.14s 起渐显、第二组 0.38s 起渐显、1.34s 前同时保持、1.78s 淡出、2.4s 重新开始；「轮流亮灭」已确认不采用，仅留作对照。全程 ease-in-out，无硬切，三端用同一组时间参数。
  • 动画分组：实际 4 条弧按「内弧 / 外弧」各一组（每组左右对称同时亮）是默认方案；切「左右交替」则变成左边一组、右边一组。这是落地前最后一个待确认口径。
  • 配色对比度：P1 小标题 #22C55E 在白底仅 2.3:1（不达 AA 4.5:1）；调深为 #15803D 后 5.0:1；小标题灰 #6B7280 为 4.8:1；深色 #4ADE80 / #9CA3AF 在 #1C1D20 上约 9.7:1 / 6.6:1，均达标。
