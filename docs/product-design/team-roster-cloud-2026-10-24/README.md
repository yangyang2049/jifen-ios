## 核心结论

1. 队伍独立于小组：可以不建小组，直接离线建队、管理队员、计分和积累本机战绩。
2. 多人邀请、跨设备访问和共享统计需要新的云端队伍领域；上云按用户选择进行，不把登录等同于上传全部本机资料。
3. 队伍和队员不是一组名称字符串。成员身份、访问权限、出场名单和历史显示名称分别保存。
4. 队伍可记录未注册队员；登录用户可以认领，但认领既有队员需要本人同意与队伍管理方确认。
5. 篮球首先支持队伍战绩和明确出场记录；球员得分榜依赖球员归属数据，不从球队总分推测。
6. 现有小组尚未支持篮球、足球队伍赛；这部分作为后续独立契约扩展，不能把队伍硬塞进现有单／双打席位。
