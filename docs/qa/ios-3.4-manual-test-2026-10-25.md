# iOS 3.4 手动测试清单（除微信登录／账号绑定外）

日期：2026-10-25
范围：`3.4` 分支 `553d0b48` 相对 `3.3` 标签的全部改动 + 当日未提交工作区改动（`git diff 3.3..HEAD` 与 `git status`）。
用途：提审／发版前的真机与双设备验收。微信登录与账号绑定仅保留依赖项（见第 8 节），不作为本轮重点。

## 0. 前置条件

- 构建：`3.4 (78)`，正常签名（不要加 `CODE_SIGNING_ALLOWED=NO`，会因 Keychain entitlement 产生成片假失败）。
- 后端：`https://api.jifenqi.com` 健康 200；身份／私人记录接口已于 2026-10-25 上线，能力位 `privateRecordsV1` 为真。
- 账号：Apple 账号 A（干净账号）、Apple 账号 B、微信账号 W（已有业务账号）、无账号游客。
- 设备：iPhone（小屏，如 SE 3）、iPhone（主力真机，已装微信）、iPad、可投屏电视／AirPlay 接收端（真机，非模拟器）。
- 素材：小组二维码、网页扫码登录二维码（`https://jifenqi.com/auth/qr#...`）、相册中存一张二维码截图与一张无二维码图片。
- 数据：准备一份 3.3 及更早的九球记录（缺 `ruleVersion`）、一份进行中的计分、若干计时记录。

图例：⬜ 待测　✅ 通过　❌ 不通过（备注写现象与日志）　⏸ 本轮不做
