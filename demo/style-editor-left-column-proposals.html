样式编辑面板 · 左栏布局方案对比

右栏与顶栏口径已定稿（A 底部绿线 + 分栏等高 + H=48），本页只处理左栏：segment 的对齐与落点、假底栏去留、内容纵向分布。六个方案共用同一套右栏，点击缩略图可在上方大图细看。

先说三个判断

① 左栏不该有条独立底栏。上版里那条「实时预览 · 本机」是我为了「底边也对齐」硬加的凑数元素，没有真实功能。删掉它之后，两栏仍然等高（grid 同一行，都是 500vp），只是右栏内部有 actions、左栏预览自然延伸到底——这叫职责不对称，不叫高度不一样。你上一轮要求的「左右不要高度不一样」针对的是顶栏，顶栏等高继续保持。

② segment 左对齐确实别扭。左栏本质是「记分牌预览画布」，构图是左右对称的主队/客队；「本机 / 投屏」作用于整块画布，属于画布级控件，理应跟随画布中轴。右栏 tab 是等宽通栏、天然中轴对齐；左栏 220vp 固定宽 + 18vp 左内边距，会把视觉重心拉到左边，两栏看起来不像一对。反之，如果把它当「设置项 / 工具条」语义，左对齐符合表单阅读习惯——所以留 S0 做对照，由你挑。

③ 「放底部」和「不要底栏」可以不冲突。S3 不是加一条底栏，而是把切换器贴到底部，与右栏 actions 同高同位置，那条区域装的是真实控件，底边自然对齐。S4 更彻底：把切换器并进左半顶栏，左栏只剩一块纯预览画布，预览区最大。

方案Segment 落点 / 对齐左栏底栏预览板高度相对 S0风险 / 适用
  • 推荐 S4（并入左顶栏）★：左右顶栏语义成对——左切「给谁看」（本机/投屏），右切「改什么」（主题/背景/字体/自由编辑），都在 H=48 的等高顶栏里，正好呼应「顶部通栏切成两半」；左栏没有任何凑数元素，预览画布 416vp 最大（相对 S0 +122vp）。代价是 48vp 顶栏要塞标题 + segment + 恢复默认，窄屏需隐藏「样式编辑」标题或把 segment 收成紧凑宽。
  • 次选 S3（底部切换）：担心顶栏挤就用它。左栏底部那条与右栏 actions 同高同位置，装的是真控件而不是假提示，底边对齐且预览画布 352vp（相对 S0 +58vp）。适合把「本机/投屏」理解为操作而非导航的用法。
  • S1（顶部居中 + 去底栏）是最小改动：只把 segment 居中 + 删假底栏，预览画布 358vp（+64vp），风险最低，但左栏仍有一条工具条横在画布上方。
  • S2（整体纵向居中）构图最稳，适合大屏/平板横屏，但预览板缩到约 229vp、上下各留 65vp，小屏会明显浪费空间，且分数变小。
  • S5（浮动 overlay）预览最大且最轻，但切换器会压在记分牌上，需要给比分内容留 top inset；深色主题下胶囊与画布对比也偏糊，三端实现成本最高。
  • 无论选哪个，segment 宽度建议不要固定 220vp：改为「左栏内容宽的 60%、最大 260vp」或随 H 联动，避免宽画布上显得小、窄画布上溢出。
