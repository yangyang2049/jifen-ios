样式编辑 · 窄屏顶栏装不装得下 & 降级方案

S4 把「本机/投屏」并进左半顶栏后，顶栏里就有 4 样东西：退出、标题、切换器、恢复默认。下面按三端现有真实尺寸算宽度预算，并给出窄屏降级方案（含图标、下拉、首次展开后收起）。

结论：装不下，而且不是 iPhone SE 特例。按 iOS/Android 现有 1:1 对齐的顶栏（高 56、左右内边距 12、关闭 44、标题 18sp、恢复默认 12sp 文字按钮），S4 全文字版需要 468pt（24 内边距 + 44 退出 + 72 标题 + 220 切换器 + 88 恢复默认 + 20 间距）。iPhone SE 竖屏 375pt 缺 93pt；SE 横屏切分后左栏约 360pt 缺 108pt；连 430pt 的大屏手机竖屏也差 38pt。只有 iPad 横屏（左栏约 553pt）才宽松，余 85pt。

所以 S4 必须带断点降级。好消息是三端已经有可复用的断点：鸿蒙 ScoreboardStyleLayoutMetrics.ts:3 定义 LARGE_VIEWPORT_MIN_WIDTH_VP = 900，iOS/Android 目前用「宽 ≥ 高」判断横屏分栏。把切分门槛统一到 900，窄屏根本不会走到四元素挤顶栏这一步。

  • 三端现状（本轮实查）：iOS ScoreboardStyleEditOverlay.swift:336-350 与 Android ScoreboardStyleEditOverlay.kt:353-371 是 1:1 对齐的——顶栏 56、padding 12、关闭 44、标题 18sp、恢复默认 12sp；分栏条件都是 width >= height，右栏占 46%，竖屏上下 43%/57%。PreviewTargetChips 上限 220、高 44、字号 12。鸿蒙形态不同：是浮层面板，ScoreboardStyleLayoutMetrics.ts 用 900×560vp 断点、面板宽 300~420vp，本来就没有「通栏切两半」，若要统一形态得先决定。
  • 你的三个点子都能用：① 切换器改双图标（📱/📺）省 132pt，但语义需要学习，建议只在窄屏用；② 改下拉「本机 ▾」省 124pt，省空间但切换多一次点击，且当前态只剩一个字，不如双图标直观；③ 首次展开文字、之后收成图标最划算——建议做成通用规则而非窄屏专属，大屏也用，可减少常驻文字噪声。
  • 渐进披露实现要点：N4 收起后需 344pt（375 下余 31pt），但首次真展开文字是 388pt——375 竖屏超 13pt、360pt 的 SE 横屏左栏超 28pt（默认组合即可看到，切到「SE 横屏」更明显）。所以窄屏首次提示应做成不占布局宽度的气泡指向 ↺ 图标，或首次临时淡出标题；只有 ≥430pt 才允许真撑开。持久化标记用 iOS UserDefaults / Android SharedPreferences / HOS Preferences，键名三端统一；图标必须带 accessibilityLabel，长按可显示完整文案；提供「设置里可重新开启提示」避免用户找不到。
  • 标题是第一个可以让位的东西：窄屏隐藏「样式编辑」省 72pt，比把切换器变图标更不伤可发现性——退出按钮和右下角保存已经说明当前在编辑态。N3 就是这个思路。
  • 断点建议用可用窗口宽而不是设备类型或方向（鸿蒙注释里已写了这个理由：避免平板分屏 / 桌面自由窗口误判）。旋转、分屏时要实时重算，别只在进入时算一次。
  • 此页只做方案与宽度预算对比，尚未落到三端代码；你选定后我再连同 S4 一起实施。
